# Имитация поиска на сайте https://www.autozap.ru/

---

### Используемые инструменты:

- ООП
- Composer
- guzzlehttp/guzzle
- symfony/dom-crawler
- symfony/css-selector

---

### Как проверить работу:

После клонирования, выполнить установку зависимостей composer-a. Далее можно выполнять скрипт командой:

```php
php index.php {указание артикула} (если не указать, код будет запрошен все равно)
```

Файл с данными сохранится в папку /storage.

---

### Примечание:

- В скрытых элементах ответа, есть дубликаты производителя, наименования и тд, которые не соответствуют выдаче на сайте.
- На сайте идет динамическая подгрузка цен из js, поэтому обычный парсинг не даст актуальных цен, которые видны на сайте. В данном случае, я посчитал оверхедом имитацию браузера для получения актуального HTML, после отработки JSON.
