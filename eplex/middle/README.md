# Вычисление наиболее дешевого варианта закупки

---

### Используемые инструменты:

- PHP 8.4
- ООП
- Composer

---

### Как проверить работу:

После клонирования, выполнить установку зависимостей composer-a. Далее можно выполнять скрипт командой:

```php
php index.php
```

Далее нужно выбрать список поставщиков (предложений) из списка. Весь список описан в файле suppliers-list.php. Его можно редактировать для проверки.

Следующим пунктом указывается число N.
