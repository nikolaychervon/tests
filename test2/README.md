# Тестовое задание 
Приложено в виде PDF.

----

### Используемые инструменты:

- PHP 8.4
- Laravel
- ООП
- Composer
- Docker
- Redis
- php-stan / phpcs
- Makefile

---

### Как проверить работу:

После клонирования, выполнить билд проекта:

```shell
  make build
```

Команда сама запустит контейнеры, установит зависимости и создаст ключ приложения.

После выполнения скрипта, можно открывать сайт: http://127.0.0.1/

У сайта есть 3 эндпоинта:

```php
  [GET]  / - страничка, на которой будет список пользователей
  [GET]  /api/list - API эндпоинт, который возвращает всех пользователей (nickname, avatar)
  [POST] /api/register - API эндпоинт, который создает пользователя (принимает: nickname, avatar)
```

Фронт и бэк части живут отдельно. На фронте список пользователей получается путем запроса на API через js.

Настройки по умолчанию:
- Команда на удаление пользователей срабатывает **раз в минуту**
- Пользователи удаляются, если были созданы **позже 1 минуты от текущего времени**
- Запросы ограничены. (/ - 30 в минуту, /api/* - 20 в минуту)
- Аватар должен быть png / jpg / jpeg, не более 2048кб
